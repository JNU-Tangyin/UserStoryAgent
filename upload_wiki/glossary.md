# Public-Safe Glossary

This glossary keeps only concepts useful for user-story interpretation and rewriting. It excludes concrete endpoints, credentials, internal hostnames, IPs, and configuration values.

## CMMS

Computerized Maintenance Management System; maintenance, work-order, spare-part, calibration, and preventive-maintenance context.

## Edge Automation

Shop-floor edge automation concept; endpoints and connectivity settings are excluded.

## IIoT

Industrial Internet of Things concept; connection and configuration details are excluded.

## Inventory Essentials

Inventory and material-control context for production-control user stories.

## Kit Verify

Production-control context for verifying required materials or kits.

## MES

Manufacturing Execution System; the manufacturing-domain system context for the user stories.

## OEE

Overall Equipment Effectiveness; production-efficiency and shop-floor-performance context.

## Production Workbench

Shop-floor execution workspace context for production-related user stories.

## SPC

Statistical Process Control; quality-monitoring context for process metrics and dashboards.

## SQC

Statistical Quality Control; quality-related configuration and control context.

## Traceability

Tracking materials, parts, serialized items, production events, and related records through manufacturing processes.

## Widget Builder

Configurable widget/dashboard context for administration-related user stories.

## XConnect

Integration/automation concept; concrete endpoints and connectivity settings are excluded.
